## Phase 3.1 — Deploy Backend to Render

### Step 1: Push code to GitHub

```bash
cd "AI Post Assistant"
git init
git add .
git commit -m "v12 — production ready with API key auth + Chrome extension support"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ai-post-assistant.git
git push -u origin main
```

**Important:** Verify `.gitignore` excludes `.env`, `node_modules/`, `data/*.json`. Run:
```bash
git status
# Should NOT show: .env, node_modules/, data/users.json
```

### Step 2: Create Render Web Service

1. Go to https://dashboard.render.com
2. Click **New +** → **Blueprint**
3. Select your GitHub repo
4. Render auto-detects `render.yaml` → confirms the service config
5. Click **Apply**

### Step 3: Set environment variables

In Render dashboard → your service → **Environment** tab, set these manually (the ones marked `sync: false` in render.yaml):

| Variable | Value |
|---|---|
| `OPENAI_API_KEY` | `sk-prod-...` (your real OpenAI key) |
| `GEMINI_API_KEY` | (optional, for fallback) |
| `SUPABASE_URL` | `https://xxxx.supabase.co` |
| `SUPABASE_ANON_KEY` | `eyJ...` |
| `SUPABASE_SERVICE_ROLE_KEY` | `eyJ...` |
| `RAZORPAY_KEY_ID` | `rzp_test_...` (test mode) or `rzp_live_...` (live) |
| `RAZORPAY_KEY_SECRET` | (from Razorpay dashboard) |
| `RAZORPAY_WEBHOOK_SECRET` | (from Razorpay webhooks page) |

**`SESSION_SECRET`** is auto-generated by Render (don't set manually).

### Step 4: Deploy

1. Click **Create Web Service**
2. Wait 2-5 minutes for build + deploy
3. Render gives you a URL like: `https://ai-post-assistant-backend.onrender.com`
4. Test: visit `https://YOUR-URL.onrender.com/api/health` in browser
5. You should see:
   ```json
   {
     "success": true,
     "app": "PostReady AI",
     "version": "10.0.0",
     "env": "production",
     "aiProvider": "openai",
     "database": "supabase",
     "razorpay": "configured"
   }
   ```

### Step 5: Run database migration

```bash
# Run locally with production env vars
cd "AI Post Assistant"
SUPABASE_URL=your_prod_url SUPABASE_ANON_KEY=your_prod_key SUPABASE_SERVICE_ROLE_KEY=your_prod_key \
  npm run migrate
```

This creates all tables in Supabase + migrates any existing JSON data.

### ⚠️ Common Render issues

| Issue | Fix |
|---|---|
| Build fails: "Cannot find module" | Check `package.json` has all deps. Run `npm install` locally, commit `package-lock.json` |
| App crashes on startup: "FATAL: AI_PROVIDER=mock" | Set `AI_PROVIDER=openai` + `OPENAI_API_KEY` in Render env |
| App crashes: "FATAL: SESSION_SECRET is default" | Don't set `SESSION_SECRET` manually — let Render auto-generate it |
| CORS errors from frontend | Add your Vercel URL to `ALLOWED_ORIGINS` |
| 502 Bad Gateway | Check Render logs — likely missing env var |
| Free tier sleeps after 15 min | Upgrade to Starter ($7/mo) for always-on |

## Phase 3.2 — Deploy Frontend to Vercel

### Step 1: Push frontend to GitHub

Your frontend is in the `frontend/` subfolder. You have 2 options:

**Option A: Same repo (recommended)**
- Keep frontend in same repo
- Vercel will detect it

**Option B: Separate repo**
```bash
cd frontend
git init
git add .
git commit -m "frontend"
git push origin main
```

### Step 2: Create Vercel project

1. Go to https://vercel.com/dashboard
2. Click **New Project**
3. Import your GitHub repo
4. **IMPORTANT settings:**
   - **Root Directory:** `frontend` (if same repo)
   - **Framework Preset:** Next.js
   - **Build Command:** `npm run build` (auto-detected)
   - **Output Directory:** `.next` (auto-detected)
5. Click **Environment Variables** and add:
   ```
   NEXT_PUBLIC_API_URL = https://ai-post-assistant-backend.onrender.com
   ```
   (replace with your actual Render URL)
6. Click **Deploy**
7. Wait 1-2 minutes
8. Vercel gives you: `https://ai-post-assistant.vercel.app`

### Step 3: Update backend CORS

Back in Render → Environment → update `ALLOWED_ORIGINS`:
```
https://ai-post-assistant.vercel.app,chrome-extension://*
```

Save → Render auto-redeploys (2-3 min).

### Step 4: Test production

1. Visit `https://ai-post-assistant.vercel.app`
2. Sign up
3. Generate a post
4. If it works → you're live!

### ⚠️ Common Vercel issues

| Issue | Fix |
|---|---|
| Blank page | Check browser console — likely `NEXT_PUBLIC_API_URL` not set |
| API calls return 401 | Backend CORS not allowing your Vercel URL → update `ALLOWED_ORIGINS` |
| Build fails on Vercel | Run `npm run build` locally — fix any TypeScript errors first |
| Fonts not loading | Vercel should auto-fetch from Google Fonts. If blocked, self-host fonts |

## Phase 3.3 — Configure Razorpay Webhooks

### Step 1: Get webhook URL

Your webhook endpoint is:
```
https://ai-post-assistant-backend.onrender.com/api/razorpay/webhook
```

### Step 2: Add webhook in Razorpay

1. Go to https://dashboard.razorpay.com
2. **Settings** → **Webhooks** → **Add New Webhook**
3. **Webhook URL:** paste your URL above
4. **Secret:** generate one (or let Razorpay generate)
5. **Events to subscribe:**
   - `payment.captured`
   - `payment.failed`
   - `subscription.activated`
   - `subscription.cancelled`
6. Save

### Step 3: Add webhook secret to Render

Copy the webhook secret → Render → Environment → `RAZORPAY_WEBHOOK_SECRET`

### Step 4: Test webhook

1. Make a test payment
2. Check Razorpay dashboard → Webhooks → should show "Sent" + "200 OK"
3. Check Render logs → should show `[razorpay] webhook event: payment_captured`

## Phase 3.4 — Set Up Custom Domain (Optional, after launch)

### Vercel custom domain
1. Vercel → your project → **Settings** → **Domains**
2. Add `yourapp.com`
3. Update DNS: add CNAME record pointing to `cname.vercel-dns.com`
4. Wait 5-30 min for SSL to provision

### Render custom domain
1. Render → your service → **Settings** → **Custom Domain**
2. Add `api.yourapp.com`
3. Update DNS: add CNAME record pointing to your Render URL
4. Wait 5-30 min for SSL

### Update env vars after custom domain
- Vercel: `NEXT_PUBLIC_API_URL=https://api.yourapp.com`
- Render: `ALLOWED_ORIGINS=https://yourapp.com,chrome-extension://*`
- Razorpay webhook: update to `https://api.yourapp.com/api/razorpay/webhook`

## 🚨 Disaster Recovery

### If backend goes down
1. Check Render logs: dashboard → your service → **Logs**
2. Common fixes:
   - Missing env var → add it → Render redeploys
   - OpenAI API key expired → generate new one → update env
   - Supabase connection failed → check if Supabase project is paused (free tier pauses after 7 days idle)

### If database corrupts
1. Supabase → **Database** → **Backups** → restore from daily backup
2. Or run `docs/SUPABASE_SCHEMA.sql` again (idempotent — safe to re-run)

### If you need to roll back
1. Render → **Deploys** → click any previous deploy → **Roll Back**
2. Vercel → **Deployments** → click any previous → **Promote to Production**
